\section*{Software and data availability}
\label{sec:availability}

\IC{} is open source at \url{https://github.com/MACSYS-CoE/InferCell}, with
documentation at \url{https://macsys-coe.github.io/InferCell/}. The test suite has
\pn{fw.tests} assertions. \placeholder{Release tag and archived DOI (Zenodo) for the
version used in this paper.} The evidence behind the scored and unscored predictions is
in an archive with SHA-256 checksums, which holds the runs' outputs and the posterior
fits they read. Each number in this paper is listed with its source file in
\texttt{paper/numbers.tex}, and each run's result note in \texttt{dev/scripts/} gives its
commit and Slurm jobs.
