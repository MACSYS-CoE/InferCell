## PR A: the combiner (src, tests, docs)

**New `src/predict_combine.jl`.** It is included after `predict.jl` in `src/InferCell.jl` and exports `combine_rows(blocks::AbstractVector{Prediction}) -> Prediction`.

The contract is already in `predict`'s docstring ("Parallel runs", `src/predict.jl:326-328`): no completion, each block with its own `rng` and disjoint `draws`, and one shared `DeltaCorrection`.

**Concatenation along rows** (vcat; `dims = 3` for the seeds):
- `draws`, `theta_I`, `sigma_b`, `seeds`;
- `cells` and `cells_intervened`;
- `mu`, `sigma2`, `n_ok`, `effect`, `effect_sigma2`;
- `viable`, `decisions`;
- `provenance.pairs`.

**Recomputed with `predict`'s own helpers.** The blocks' `summary`, `effect_summary` and `statuses` are never read.
- The weights are uniform, `fill(1/M, M, 1)`, with `conditioning.uniform = (; acceptance = 1.0, ess = _kish(u))`.
- `summary` comes from `_summary(mu, s2, nok, w, shift, forward)` (`src/predict.jl:136`).
- `effect_summary` comes from `_summary` on `effect`, plus `_n_failed_intervened` (`:168`), with the same shifts as `_assemble` (`:518,530`).
- `statuses` comes from `_status_counts` (`:173`).

**Provenance:**
- `fork_seed` and `threads` become per-block vectors;
- `settings.n_parameter_draws` becomes M;
- every other setting must match across blocks.

**Refusals**, each with a message:
- an empty input;
- completion ≠ `:none`;
- a mismatch across blocks in any of: forward, quantity (`isequal` on the definition), horizon, estimand, intervention, `n_cells`, version, `held`/`theta_H`, or the posterior's `source`;
- draws that repeat across blocks;
- cell seeds that are not unique across blocks (the E[σ²]/n condition, note §2). Two blocks given the same rng trip this;
- a block whose `settings.delta === :ensemble`, since each such block computed its own δ;
- blocks whose δ objects differ (seeds, `delta`, `delta_intervened`, fingerprint);
- for the hybrid, a block with a δ.

**No line of `predict`/`_assemble` changes.** So the freeze's old-against-new gate doesn't apply, and `test_predict_reference.jl` still runs as the check. If the implementation does end up touching `predict.jl`'s code, rerun `dev/scripts/make_predict_reference.slurm` (93abbce against the head) before any M5 job.

**Docs:**
- `combine_rows`' docstring;
- an `@docs` entry in `docs/src/api/predict.md`;
- a pointer from `predict`'s "Parallel runs" paragraph (docstring text only).

**New `test/test_predict_combine.jl`**, included after `test_predict.jl` in `test/runtests.jl`. It runs on M0 at 60 s, with `_toy_posterior` as in `test/test_predict.jl`:
1. **Single call, mean field.** The mean field is deterministic. Two blocks with disjoint draws, a shared small `delta_correction` and the knockdown are combined. The result must equal one call over the union: `mu`, `effect`, `summary` and `effect_summary` exactly.
2. **Single call, hybrid (slice and recombine).** One `predict` (M = 4, `n_cells = 3`, knockdown) is sliced into blocks [1], [2:4] by a test helper. The helper plants wrong summaries in each block. `combine_rows` must reproduce every field of the single call exactly.
3. **Real blocks.** Two `predict` calls with different rngs and disjoint draws. The combined per-row fields equal the blocks'. The summary equals the equal-weight formulas computed by hand: mean, `var`, mc = mean(σ̂²/n), intrinsic = mean(σ̂²).
4. **Common seeds.** Two different posteriors with the same rng and block shape give `p1.seeds == p2.seeds`. This documents the property M0 relies on.
5. **Every refusal above.**

## PR B: the M0 launcher, the scoring, the pre-registration, the smoke

**`dev/scripts/m0_evidence_kim40.jl`.** It includes `pilot_common.jl` for `save`, `plain` and `COMMIT`/`JOB`/`SMOKE`. All logic sits in functions (soft scope). The header declares every rule and seed. Its stages:

- **`prep`** (one small job). It loads the 50 V7 replicates and the 50 B7 fits (both chains) with `posterior_draws`. It reads no Q. It checks:
  - names = `M0_TARGETS`;
  - V7 and B7 truths are equal per dataset, σ_b included;
  - the draw counts are 556 and 400.

  The draws are `round.(Int, range(1, N; length = 100))`, split into 10 blocks of 10. The stage writes `manifest.jls` and a TSV.
- **`work <i>`**, one array, 1,150 tasks:
  - **δ** (r, p), the first 100 tasks: `delta_correction(metered(m0_models()), haldane_values(ms, InferCell._theta_ref(pd)), seeds; horizon = 600, intervention = Knockdown(; dose = 0.3), threads = false)`. This mirrors `predict`'s internal δ path. The seeds are `_cell_seeds(Xoshiro(19_541_000 + r), 9_849)`, shared by V7 and B7;
  - **truth** r, the next 50: `predict` on a one-draw `PosteriorDraws` holding θ*, so the truth runs the same code path as the predictions. It uses `n_cells = 9_849`, the knockdown and `rng = Xoshiro(19_541_500 + r)`;
  - **hybrid block** (r, p, b), the last 1,000: `predict(m0_models(), pd; horizon = 600, n_cells = 887, draws = block, intervention = Knockdown(; dose = 0.3), rng = Xoshiro(19_540_000 + 10(r−1) + (b−1)), threads = false)`. The rng doesn't depend on p, so the seeds are common to V7 and B7.

  Each task refuses if its output already exists, so nothing is overwritten. It saves the full object (read back at the same commit) and its `plain` form.
- **`finish <r,p>`**, an array of 100 tasks:
  - `combine_rows` over the 10 blocks;
  - the mean field: `predict(...; forward = :mean_field, draws = the 100, delta = dc, intervention, rng = Xoshiro(19_541_200 + r))`. One call is enough at about 0.4 s per solve, and it gives both the uncorrected mean field (`mu`) and the corrected one (`summary.mean`);
  - the asserts: the hybrid's draws equal the mean field's (paired draws); V7's combined seeds equal B7's for r; block, δ and truth seeds are disjoint;
  - it saves the combined `plain` form. The blocks stay the raw record, which halves the disk use.
- **`score`** (one job). It refuses if any output is missing.
  - **Arms, per dataset:** {V7, B7} × {hybrid, MF uncorrected, MF δ-corrected}, for Q and for ΔQ (KIM-41 reads the ΔQ tables).
  - **Intervals:** central empirical quantiles (`quantile`, type 7) of the 100 values, at 50% and 90%.
  - **Coverage** of the truth μ̂(θ*) (and Δμ̂(θ*)) across the 50 datasets, with binomial SEs.
  - **Sharpness:** the 90% width, as the median over datasets, plus each dataset's width ratio to V7-hybrid (median and IQR).
  - **Secondary:** the truth's PIT rank among the 100 values.
  - **The table's effects:** each dataset's predictive-mean difference against V7-hybrid, in units of V7-hybrid's SD.
  - **Reported beside the scores:**
    - the intrinsic spread (the hybrid's `intrinsic_var`, and the truth's σ̂²);
    - each dataset's MC share (`mc/var`) and truth SE ÷ predictive SD, against the 10% rules;
    - `statuses` and failed counts;
    - pairs with no Q, which leave the scores and are counted.

  It writes `score.md` and `score.jls`.

**`dev/scripts/m0_evidence_kim40.sh`.** It sources `launcher_guard.sh` (`sub`, `record`, `run`). Modes:
- the default run: a precompile job on milan, then `prep`, then the `work` array (`%150`, `--time=24:00:00`, `--mem` from the smoke). `finish` and then `score` follow on `afterany` dependencies with completeness checks, so a failed task never leaves jobs stuck; `scancel` is blocked from here;
- `missing`: resubmits only the absent work outputs, then `finish` and `score`.

Job ids go to `jobs.tsv`. The time is about 10 draws × 887 cells × 3.4 s ≈ 8.4 h median per block task, and about 9.3 h per δ or truth task.

**§12 entry, "KIM-40: M0's run plan and scoring, declared before the run (pre-registration)".** It records:
- the scoring above, for Q and for ΔQ;
- the intervals, used as they are;
- the common seeds and the seed allocation: 19_540_000–19_541_999 for KIM-40/41, with the smoke at 19_541_900+. KIM-42 keeps 19_542_xxx;
- the draw rule, the blocks and the combiner;
- the truth computed via `predict`;
- the mean field reported uncorrected and corrected;
- the launch gates;
- that this answers KIM-70's combiner point.

**The smoke pass** (SMOKE=1, the full DAG on Slurm).
- It runs on the held-out v6 only. The exact slot is B7 v6 chain 1 and the mixed slot is chain 2, both stand-ins. It reads no evidence dataset's Q. `prep` still validates the real 100 files.
- The sizes: 60 s, `n_cells = 3`, 2 blocks of 2, n_ref = n_truth = 4.
- It records maxrss, task times and file sizes, which set `--mem` and project the disk use. The estimate is about 1 KB per cell, about 20 GB in all; check the /fred quota.
- It checks the seed equality, the combine and the read-back.
