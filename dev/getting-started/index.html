Getting started

Installation

InferCell is a Julia package targeting Julia 1.10. Clone the repository and instantiate the project:

git clone https://github.com/MACSYS-CoE/InferCell.git
cd InferCell
julia --project -e 'using Pkg; Pkg.instantiate()'

Run the reduced syn3A model

build_corea composes all seven modules and checks the composition is complete: every state has an owner and no moiety is stranded. It returns a HandshakeDriver, which run_handshake! steps one simulated second at a time.

using InferCell, Random

Random.seed!(1)
d = build_corea(; tspan = (0.0, 180.0))
rec = run_handshake!(d, 180)
rec.t[end], size(rec.jump)

rec holds both blocks' states and parameters at every handshake, with the cell's geometry, the clipping census and the rate-constant rebuilds. Seeding the global generator before the build fixes the cell.

Fit a synthetic dataset

The sampler is validated on M0, a two-gene reference system cut from the same model. m0_dataset draws a truth from the prior and simulates a population of cells under it. gibbs_setup holds what a chain keeps fixed, and gibbs_sweep! is one sweep of the three-block sampler.

ds = m0_dataset(16085; ncells = 3, horizon = 180)
g = gibbs_setup(ds; N = 4, horizon = 180)

rng = Xoshiro(2)
start = Dict(draw_truth(rng, g.models; names = M0_TARGETS, purpose = :calibration).values)
s = gibbs_init(rng, g; cme = [start[n] for n in g.cme],
               u = [log(start[f]) for f in g.forwards], σ = rand(rng, SIGMA_MET_PRIOR))
for _ in 1:5
    gibbs_sweep!(s, g)
end
s.trace[end]

The chain's free parameters are the two promoter strengths and the transcript decay constant (g.cme), the log enolase and aldolase forward constants (g.forwards), and the metabolite noise scale σ. This example is small enough to run in minutes. A production chain uses 50 cells over 600 s with N = 20 particles, and one sweep takes about 13 minutes on five threads. See the conditional sampler.

Predict

predict turns a posterior into a prediction of a quantity Q, here the lactate a cell exports. posterior_draws reads any posterior InferCell writes: the Chains that infer returns, or an archived V7 or B7 file by its path.

ms = m0_models()
ch = infer(ms, ds; route = :exact, rng = Xoshiro(3), n_sweeps = 5, N = 4)
pd = posterior_draws(ch)

# Four stochastic cells for each of three posterior draws.
p = predict(ms, pd; horizon = 180, n_cells = 4, n_parameter_draws = 3, rng = Xoshiro(4))
p.summary.uniform

# The mean field, uncorrected and corrected by a hybrid ensemble at one point.
m = predict(ms, pd; horizon = 180, forward = :mean_field, delta = :ensemble, n_ref = 8,
            rng = Xoshiro(4))
m.summary.uniform.mean, m.delta.delta

# The paired effect of a 25% ptsG promoter knockdown, on the same cells.
k = predict(ms, pd; horizon = 180, n_cells = 4, n_parameter_draws = 3,
            intervention = Knockdown(; dose = 0.25), rng = Xoshiro(4))
k.effect_summary.uniform.mean

summary separates three parts of the spread: the parameter uncertainty (parameter_var), the Monte Carlo part that a finite number of cells adds (mc), and the cell-to-cell spread (intrinsic_var). The last is reported apart, since the estimand is a population mean. parameter_var is the parameter variance only without completion, as here. On the reduced model (d11_models()), the parameters M0 does not infer are completed from their priors with completion = :prior, or filtered by a declared ViabilityRule with completion = :viability_conditioned_prior. See Prediction.

Running the tests

julia --project -e 'using Pkg; Pkg.test()'

The suite takes about an hour on four cores. On a Slurm cluster, run sbatch test/run_tests.slurm.
