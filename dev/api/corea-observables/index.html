Core A′ observables and synthetic data

What the likelihood may condition on, and the synthetic data it is fitted to (spec §11 phase 15). This page covers:

  • the circularity guard and the truth-drawing rule of spec §4 D8;
  • the 60 s observables, fluxes and replicate ensembles;
  • the ensemble sensitivity and its noise-floor rank test;
  • output F2 on check 8's frozen-expression variant;
  • the dataset generator;
  • M0, the two-gene reference system of phase 16 (task 16a.8), and its datasets.
InferCell.POLYMERASE_DIRECTION — Constant
POLYMERASE_DIRECTION

The seventh column of task 15.8's Jacobian. Transcription reads the polymerase turnover as the constant RNAPOL_KCAT and multiplies it by each promoter strength, and the turnover ceiling never binds (spec §4 D11). So scaling the constant is exactly scaling all 17 promoters together, and that is how the column is taken.

InferCell.assert_no_circularity — Method
assert_no_circularity(models, observables; free = Symbol[]) -> Nothing

Spec §11 task 15.1 and §4 D8. Throws if observables includes a protein count (see protein_count_states), or if a protein count's initial condition is free, either in models or in the extra parameter names free. The error names the seventeen promoter parameters the loop would double-count. Metabolite concentrations, transcript counts and the cell volume pass.

InferCell.check_identifiability — Method
check_identifiability(J::AbstractMatrix, noise::AbstractMatrix) -> NamedTuple

Spec §11 task 15.8 and §8 K6 for a Monte Carlo Jacobian (§12 2026-09-29, phase 15 planning). noise is the split-half matrix (J_A − J_B)/2 from disjoint halves of the seeds. It carries J's Monte Carlo error and none of its signal, and its largest singular value is the noise floor. The rank is the number of J's singular values above that floor, and the set is identifiable when that equals its parameter count.

Returns (singular_values, floor, rank, n_params, full_rank, condition). The condition number is capped by the largest singular value over the floor, so it is reported, not gated.

InferCell.check_truth — Method
check_truth(models, truth; names = D11_TARGETS) -> Nothing

Refuse a truth set that is not a smoke test and that puts any target at its nominal published value, and any truth that breaks a reaction's equilibrium constant (via assert_haldane). A value drawn from a continuous prior lands exactly on the nominal with probability zero, so an exact match means the truth was set, not drawn.

InferCell.draw_truth — Method
draw_truth(rng, models; names = D11_TARGETS, purpose = :coverage) -> NamedTuple

Spec §11 task 15.2 and §4 D8: one ground truth for a synthetic dataset, drawn from the prior by draw_parameters under the Haldane-consistent rule of task 14c.1. Each reversible reaction a draw touches keeps the equilibrium constant its nominal Mode values imply (§12 2026-09-28 A). Returns (values, purpose, label), where values is ready for set_parameters! and label is the T2 row the rule adds.

A truth for purpose = :smoke is not drawn. Use nominal_truth.

InferCell.emit_ensemble — Method
emit_ensemble(build, seeds; every = 60, horizon = nothing) -> NamedTuple

Spec §11 task 15.3 over replicate cells. build() returns (models, driver) for one fresh cell. Each is run by emit_observables! under Random.seed!(seed), seeded before the build and again before the run, as the phase-14 drivers do, so a seed fixes a cell.

Returns (times, seeds, species, counts, reactions, fluxes, volume, genes, transcripts). counts is replicates × species × times and fluxes replicates × reactions × times. transcripts is an Int array of replicates × genes × times: per-cell counts, not a replicate mean, which is what a count likelihood needs (§4 D8, §10 R14).

source
InferCell.emit_observables! — Method
emit_observables!(d, models; every = 60, horizon = d.t_end) -> NamedTuple

Spec §11 task 15.3: run the driver to horizon, and at t = 0 and every every handshakes (the published 60 s cadence at the 1 s handshake) record the candidate observables:

  • counts, species × times: every ODE state in particles, with its carried remainder, so both rounding policies report the amount they hold, and every jump species as its count. The deferred cost counters are bookkeeping, not species, and are left out.
  • fluxes, reactions × times, in mM/s, from reaction_fluxes.
  • volume, in litres.

Returns (times, species, counts, reactions, fluxes, volume).

InferCell.ensemble_jacobian — Method
ensemble_jacobian(plus, minus, nominal; delta, ncells = 200) -> Matrix

Spec §11 tasks 15.6 and 15.8. Each column is the central difference, in ln θ, of an ensemble mean: (mean(plus) − mean(minus)) / 2delta. plus, minus and nominal are replicates × rows arrays, one per column for plus and minus. Each row is divided by its resolution, so one unit is one resolution unit of an ncells-cell dataset. The resolution is the standard error of the row's nominal mean, std/√ncells, floored at rel times max(|mean|, floors[row]): as in task 14c.5's gate, a shift below 1% of the larger of the value and its particle floor is not taken as resolvable. Without that floor, a row with almost no cell-to-cell spread (t = 0, or a pool the dynamics pin) would dominate the matrix. A row whose resolution is still zero is returned as zeros.

InferCell.generate_dataset — Method
generate_dataset(truth, seeds; models = d11_models(), horizon = COREA_CYCLE_S,
                 every = 60, noise = nothing, scales = Dict(), noise_seed = 0,
                 names = D11_TARGETS)
    -> NamedTuple

Spec §11 task 15.7: a synthetic dataset from the published model (clamped drain, fractional carry), with truth written by set_parameters!, one cell per seed. The truth must pass check_truth over names, so a nominal truth is refused unless it is labelled a smoke test (§4 D8). M0 passes its own M0_TARGETS.

Each cell is run by emit_ensemble. The latent record keeps every candidate observable except protein counts (assert_no_circularity). When noise is a NoiseModel, its species are also observed with that noise at scales, from a generator seeded by noise_seed. Transcripts stay exact counts.

Returns (truth, seeds, noise_seed, scales, times, species, latent, genes, transcripts, observed, observed_species, report). latent is cells × species × times, transcripts an Int array of cells × genes × times, and report the reduction_report of the model that produced the data.

InferCell.observe_bulk — Method
observe_bulk(latent, species, panel; sigma, noise_seed, floor = 1.0) -> Matrix{Float64}

Bulk metabolite observations (spec §12 2026-10-05): for each panel pool at each save, one measurement of the mean over the latent record's cells (cells × species × times), lognormal at sigma, max(x̄, floor)·exp(sigma·ε), from a generator seeded by noise_seed. Returns panel × times. The mean is of particle counts over the same cells at every save; both are stated idealisations.

source
InferCell.observe_latent — Method
observe_latent(latent, species, noise; scales, noise_seed) -> (observed, observed_species)

Observe a latent cells × species × times record under a NoiseModel. A :lognormal species is max(x, floor)·exp(σ·ε) with its modality's σ from scales, from a generator seeded by noise_seed. A :poisson species, a transcript count, is kept exact. Only the noise model's species are returned, in modality order.

InferCell.perturbed_values — Method
perturbed_values(models, name, factor) -> Vector{Pair{Symbol, Float64}}

The parameter writes that scale name by factor from the nominal values, ready for set_parameters!.

  • A forward catalytic constant takes its reaction's reverse constant with it, derived through the nominal equilibrium constant as spec §11 task 14c.1 draws do. So the perturbed model keeps every equilibrium constant.
  • POLYMERASE_DIRECTION scales every promoter strength.
  • Any other name is scaled alone.

InferCell.protein_count_states — Method
protein_count_states(models) -> Vector{Symbol}

Every state in models that is a protein count: translation's per-gene protein states and its cytosolic ptsG, and the eight phosphotransferase carrier states. The carriers count here too. Their initial conditions are proteomics counts times proteomics fractions (§4 D7), so observing them closes the same loop as observing a translated protein.

InferCell.reaction_fluxes — Method
reaction_fluxes(u, p, t, m, u_inputs) -> Vector{Pair{Symbol, Float64}}

One ODE module's net reaction rates, in mM/s, named by reaction. Together the four Core A′ ODE modules give all 22: ten glycolytic, five recycling, the five phosphotransferase steps plus lactate export, and charging. Spec §4 D8 keeps fluxes as a reported diagnostic and out of the likelihood.

FrozenDemand(; tl_scale = 1.0, gtp_scale = 1.0)

InferCell.concentration_control — Function
concentration_control(cp = frozen_control_problem(); tol_sum = 1e-6,
                      tol_der = 1e-5) -> NamedTuple

Output F2: gene-level concentration control coefficients of the metabolite pools, C[i, g] = ∂ln xᵢ/∂ln E_g, at the frozen variant's steady state. Check 8 guards it on both halves: the summation identities within tol_sum, and every coefficient against re-solved steady states within tol_der. Either failing throws, so no F2 exists without its guard.

The thirteen gene columns sum each gene's reactions (frozen_gene_groups). The four phosphotransferase genes set carrier totals, which multiply no rate, so they have no column here (spec §3 check 8, amended 2026-09-26). The rows are the metabolite pools. The carrier states are protein counts and are left out, since spec §4 D8 rules them out of the likelihood (protein_count_states).

Returns (C, genes, metabolites, steady, summation, derivatives). steady is each metabolite's steady value in mM, summation the worst deviation of the identities, and derivatives the worst coefficient difference.

InferCell.metabolite_panel — Method
metabolite_panel(f2; threshold = 0.1, exclude = Symbol[]) -> NamedTuple

Spec §4 D9: choose the metabolite panel from F2's largest rows rather than by argument. Each metabolite is ranked by its row's largest |∂ln x/∂ln E| over the genes. The panel is every metabolite at or above threshold: a 10% change in some enzyme moves it by at least 1% at the default. exclude removes pools a validity check has already ruled out, such as check 1b's (spec §3). They are still ranked, and reported as excluded.

Returns (panel, ranking). ranking is a vector of (metabolite, strength, gene, excluded), strongest first.

InferCell.m0_dataset — Method
m0_dataset(replicate_seed; ncells = 50, horizon = M0_HORIZON_S) -> NamedTuple

One M0 replicate, everything drawn from one recorded seed (spec/phases/16-recovery.md task 16a.8, V7):

  • a truth over M0_TARGETS, drawn from the prior Haldane-consistently;
  • σ from SIGMA_MET_PRIOR;
  • ncells cell seeds and a noise seed.

The cells are the published model, clamped under fractional carry. The M0_PANEL metabolites are observed lognormally at σ, floored at one particle, and M0's two transcripts exactly. The t = 0 save, the fixed initial condition, is dropped. Returns generate_dataset's record without t = 0, with sigma, replicate_seed and noise added.

Amended 2026-10-05 (spec §12): the record also carries bulk, the panel's bulk observations (panel × times, observe_bulk) at σb = sigma, and their `bulkseed. The per-cellobserved` panel is kept as the superseded observation model.

m0_models(; smoothing = nothing, genes = M0_GENES) -> Vector{AbstractSubModel}
